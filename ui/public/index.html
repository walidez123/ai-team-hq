Field guide

Every element on this console, what it's for, and how to work the crew.

1

Masthead — engine, status, clock, crew setup

Top-right. Shows the active engine (agy · antigravity), status (line clear or crew working (n)), and local time. The gear opens Crew setup to pick models, switch engines, or configure the watchdog timer.

2

The real-time line rail

The six stations a task passes through: intake, plan, build, test, review, report. Stations light up dynamically as subagents are invoked or file their shift logs. Click any station to inspect its owner, model, and shift history.

3

Console vitals & Git inspector

Shows run metrics for the active project (plus global total) and a live Git branch pill. Click the Git pill to inspect modified files and recent commits in the target repository.

4

The crew — left column

Each employee is a stamped badge: code (PM, AR, BE, FE, QA, RV, RP, EX), duty, assigned model, and project run statistics. Click anyone to route a task to them directly.

5

Templates & task intake

Click a template chip (Full Feature, Architecture Plan, Run & Fix Tests, Security Review, Explain Codebase) to pre-fill structured instructions, or type your own brief and press Ctrl/Cmd + Enter.

6

Live wire filters & scroll-lock

Filter stream output by All, Output, Thoughts, Tools, or Errors. Scrolling up automatically pauses auto-scroll so you can read without jumping; click ↓ Resume auto-scroll to follow the tail again.

7

Detach vs. Stop run

Detach disconnects your viewer so you can browse finished run replays without interrupting the live process. Stop run terminates the running CLI process tree immediately.

8

Rendered Markdown reports

Filed reports in reports/ render with formatted headings, tables, and code blocks. Use Raw MD to toggle raw source or Copy to copy the report to your clipboard.
